# Student To-Do List App 📚

A beginner-friendly task manager made with HTML, CSS, and JavaScript.

## Features
- Add and delete tasks
- Mark tasks as completed
- Filter all, remaining, and completed tasks
- View task counts
- Save tasks in browser Local Storage

## How to run
1. Download and unzip the project.
2. Open the `student-todo-list` folder.
3. Double-click `index.html` to open it in your browser.

No installation is required.

## GitHub Pages publishing
1. Create a GitHub repository named `student-todo-list`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Open **Settings → Pages** in your repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish your site. The URL will appear in the Pages section.

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser Local Storage
